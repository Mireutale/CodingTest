# 42576 완주하지 못한 선수

## 문제 설명
- 마라톤에 참가한 선수들의 이름을 모두 가진 배열 `participant`와, 마라톤에 완주한 선수들의 이름을 모두 가진 배열 `completion`이 주어짐.
- 완주를 하지 못한 선수가 단 1명일 때, 이 선수의 이름을 출력하는 함수 solution을 구현.

## 제한 조건
- 마라톤 경기에 참여한 선수의 수는 1명 이상 100,000명 이하입니다.
- completion의 길이는 participant의 길이보다 1 작습니다.
- 참가자의 이름은 1개 이상 20개 이하의 알파벳 소문자로 이루어져 있습니다.
- 참가자 중에는 동명이인이 있을 수 있습니다.

## 입출력 예시  
### 1 
```
participant : ["leo", "kiki", "eden"]
completion : ["eden", "kiki"]
return : "leo"
```
### 2
```
participant : ["marina", "josipa", "nikola", "vinko", "filipa"]	
completion : ["josipa", "filipa", "marina", "nikola"]	
return : "vinko"
```
### 3 
```
participant : ["mislav", "stanko", "mislav", "ana"]
completion : ["stanko", "ana", "mislav"]
return : "mislav"
```
### 문제 풀이

1. 설계
- 이중 for 문으로 구현은 가능하나 시간이 오래 걸릴 것.
- 동명이인이 있을 수 있으므로 tuple도 아님
- 따라서 dictionary로 구현하고, dictionary가 hash로 이루어져 검색이 빠른점을 사용

2. 구현
collections의 Counter를 활용, 딕셔너리로 생성
for문을 활용해서 participant와 completion의 개수 차이가 나는 경우 이름을 return

3. LLM의 풀이 확인
